# @forward/copy-file

在对话里的文件路径上右键，直接把**文件本身**复制到系统剪贴板，不用再「打开所在目录 → 选中文件 → 复制」。

## 用法

1. AI 生成文档后，在对话中找到它给出的文件路径或文件卡片。
2. 右键该文件路径（或文件卡片），选择 **复制文件**；右侧栏文件树里的目录右键则显示 **复制文件夹**。
3. 到访达或目标位置按 ⌘V 粘贴，得到的就是原文件。

复制成功会有「已复制文件到剪贴板」的提示。复制的是文件项目，不是文件内容，也不是路径文本。

## 限制

- 仅支持 macOS：Host 端用一小段 AppleScript 把文件写入系统剪贴板，浏览器本身做不到这一点。
- 文件必须仍然存在；路径失效时会给出失败提示。
- 需要 DSH 的桌面版（能运行本机 `osascript`）。纯浏览器版 DSH 无法访问本机文件系统。

## 实现说明

- 菜单：Client 端向 `contextMenus` 注册 `file` / `directory` 两种目标，图标走 `contextMenu.icon` 插槽。
- 通道：`POST /api/forward-copy-file/rpc`，位于 `/api` 前缀之后，沿用 Host/Origin 校验与会话 cookie。
- 路径：相对路径按当前会话的工作区根目录解析，绝对路径直接使用；写入前检查文件确实存在。
- 安全：脚本固定，路径通过 `argv` 传入，不拼接进 AppleScript 文本，文件名里的空格、引号都不会被解释成代码。
