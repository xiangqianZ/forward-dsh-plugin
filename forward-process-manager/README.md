# 项目进程管理（forward-process-manager）

一个 DeepSeek Harness 插件：在会话顶部「提交」按钮旁放一个「进程」按钮，点开即可查看属于当前会话项目目录的进程，并可以直接停止。

## 安装

在本仓库根目录执行：

```sh
dsh plugin --profile desktop add ./forward-process-manager
```

或在 **插件 → 安装插件** 里选择 `forward-process-manager` 目录。

## 功能

- 只列出属于当前工作区、且持有监听端口（TCP/UDP）的进程；每条显示 PID 与端口号。
- 归属规则：**进程归属到"启动它的那个 DSH 会话"所在的工作区**。DSH 会给派生进程注入 `DSH_SESSION_ID`，据此找到启动会话的 cwd；所以哪怕服务在命令里 `cd` 到了兄弟目录（例如从 `retail_install` 会话里 `cd ../kefu && ./kefu_bin`），它仍只显示在 `retail_install` 工作区，不会出现在 `kefu`。没有被 DSH 打标的进程（手工终端起的）才回退到命令行/cwd 匹配。
- 浮层高度随内容自适应，最高约三条服务，更多的进程在列表内滚动；标题只显示工作区目录名，悬停可见完整路径。
- 每 5 秒刷新一次列表，也可以手动点刷新；点击浮层外任意位置、按 `Esc`、点右上角 ✕ 或再次点「进程」都会关闭浮层。
- 「停止」点击后立即发送 `SIGKILL` 结束进程，无需确认，也没有「强制结束」的第二步。
- 归属主要来自启动会话的 `DSH_SESSION_ID` → 会话 cwd；无法解析会话时才回退到命令行路径或 `lsof` 报告的 cwd。Harness 自身及其祖先进程会被排除。

## 使用

会话顶部右侧的工具栏里，「提交」按钮旁边有一个「进程」按钮。点开浮层查看和停止；点击浮层外任意位置即可关闭，也可以再次点该按钮、按 `Esc` 或点浮层右上角 ✕ 关闭。

## 边界

- `ps` / `lsof` / `kill` 依赖本机可用；没有 `lsof` 时无法取得端口信息，列表为空。
- 进程列表是进程本地实时状态，Harness 重启后不保留；列表上限 100 条。
- 按会话归属需要一个可解析的 `DSH_SESSION_ID`：若该会话的日志已被清理、取不到 cwd，则该进程回退到命令行/cwd 匹配。
- 停止操作只对当前项目列表中可见的 PID 生效，且 Host 接口只允许已认证的本地页面调用。
- 该按钮不向模型注册工具；停止进程是用户在界面上的显式操作。
